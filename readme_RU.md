
# nimFLTK

Полная привязка графической библиотеки **FLTK** (Fast Light Toolkit) к языку **Nim**.  
Обёртка поддерживает кроссплатформенную компиляцию на **Linux (Fedora/Debian/Arch)** и **Windows (MSYS2/UCRT64)** и оптимизирована для Nim `v2.2.8+`.

## ✨ Ключевые особенности
- 🎯 **Процедурный API**: Вызовы в формате `funcName(widget, args)`. Точка (`.`) используется только для доступа к полям объектов.
- 📦 **Полный набор виджетов**: Кнопки, поля ввода/вывода, слайдеры, прогресс-бары, вкладки, текстовый редактор, деревья, меню и системные диалоги.
- ⚙️ **Автоконфигурация**: Флаги компилятора и линковки подтягиваются автоматически через `fltk-config`. Никаких ручных путей к заголовкам.
- 🛡 **Типобезопасность**: Явные хелперы `asWidget()` для приведения производных указателей к базовому `ptr FlWidget`.
- 📝 **Удобные шаблоны**: `withWindow`, `withGroup`, `withTabs` и др. автоматически обрамляют код в `beginGroup()` / `endGroup()`.

## 📦 Требования
В системе должны быть установлены заголовочные файлы FLTK 1.3/1.4, а утилита `fltk-config` добавлена в `PATH`.

```bash
# Fedora Linux
sudo dnf install fltk-devel

# Debian / Ubuntu
sudo apt install libfltk1.3-dev

# Arch Linux
sudo pacman -S fltk

# MSYS2 / Windows (UCRT64)
pacman -S mingw-w64-ucrt-x86_64-fltk
